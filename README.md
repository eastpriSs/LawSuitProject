# LawSuitProject

Приложение для автоматизации переноса данных из форм в Word-документы. Разработано специально для экспертной компании **ProfitExpert**.

## 📋 Описание

**LawSuitProject** — это десктопное приложение, которое упрощает и ускоряет процесс создания типовых документов (исковых заявлений, экспертных заключений и других форм) путем автоматического заполнения заранее подготовленных Word-шаблонов (`.docx`) данными, введенными пользователем через графический интерфейс.

## ✨ Возможности

- 📝 Автоматический перенос данных из интерфейсных форм в Word-документы.
- 📂 Управление и сохранение шаблонов документов.
- ⚙️ Гибкая конфигурация приложения (через внешний `config.json`).
- 🎨 Современный и отзывчивый пользовательский интерфейс на базе QML.
- 🏗 Чистая и модульная архитектура, облегчающая поддержку и дальнейшее масштабирование.

## 🛠 Технологический стек

- **Языки**: C++ (~55%), QML (~40%), CMake (~5%)
- **Фреймворк**: Qt6 (C++20 & QML)
- **Система сборки**: CMake
- **Форматы данных**: JSON (конфигурация), DOCX (шаблоны документов)
